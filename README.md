# Multi-Vendor Booking Engine

A complete multi-vendor booking ecosystem with Backend, Admin Panel, and Embeddable Booking Widget.

## 🚀 Running the Projects

You can run `start-all.bat` in the root folder to start all services automatically, or run them manually in separate terminals:

### 1. Backend API (Port 5000)
```bash
cd backend
npm run dev
```

### 2. Admin Panel (Port 3000)
```bash
cd admin-panel
npm run dev
```

### 3. Booking Widget (Port 5173)
```bash
cd widget
npm run dev
```

---

## 🛠 Project Components
- **Backend**: Express API with JWT Auth, Polymorphic Listings (Hotel, Cinema, Space, Vehicle).
- **Admin Panel**: Dashboard stats, Vendor Approval, and Listing Management.
- **Booking Widget**: Embeddable React widget for processing bookings.
